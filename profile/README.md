## Build with Univer

The demos also include **Univer Pro and other commercial SDK modules, which are licensed separately**. See the [feature comparison](https://univer.ai/compare/) for coverage.

### Choose an integration path

| SDK layer | Build into your product |
| :--- | :--- |
| [Web SDK](https://docs.univer.ai/guides) | Embed editors and extend their plugins and APIs. Use supported content plugins in Node.js with [Headless Univer](https://docs.univer.ai/guides/sheets/getting-started/node). |
| [Server SDK](https://docs.univer.ai/server) | Add real-time collaboration, history, and Office file import/export. |
| [AI SDK](https://docs.univer.ai/ai) | Give agents tools to inspect, edit, verify, and review Office content. |

## Tools for agents

Bring Office capabilities into your existing agent environment.

| Project | What you can do |
| :--- | :--- |
| [**Univer CLI**](https://github.com/dream-num/univer-cli) | Create and edit local Office files, inspect rendered results, and review isolated drafts in a browser. |
| [**DeepSeek Harness integration**](https://github.com/dream-num/dsh-univer-office) | Create connected Office content and review the agent's work inside a DSH conversation. |
| [**OpenClaw integration**](https://github.com/dream-num/openclaw-univer-office) | Connect agents to Univer Workspace, work in shared drafts, and deliver review links and exported files. |
| [**WorkBuddy integration**](https://github.com/dream-num/workbuddy-univer-office) | Work with local Office files through MCP, live previews, and draft review. **Development preview.** |

## Developer resources

- **Build with a coding agent.** [Build with Univer](https://github.com/dream-num/skills) helps your agent choose and integrate the right SDK. [Univer SDK Skills](https://github.com/dream-num/univer-sdk-skills) covers integration, custom plugins, and Node.js workflows.
- **Start from working examples.** [Sheets starter](https://github.com/dream-num/univer-sheet-start-kit) · [Docs starter](https://github.com/dream-num/univer-doc-start-kit) · [Vue examples](https://github.com/dream-num/univer-cross-framework-examples) · [Collaboration examples](https://github.com/dream-num/univer-collaboration-examples).
- **Extend your toolchain.** [Build plugins for Vite, esbuild, and Webpack](https://github.com/dream-num/univer-plugins) · [Office icons for React and Vue](https://github.com/dream-num/univer-icons).
- **Help improve Univer.** Read the [contributing guide](https://github.com/dream-num/univer/blob/dev/CONTRIBUTING.md), explore [open issues](https://github.com/dream-num/univer/issues), or contribute to the [documentation](https://github.com/dream-num/documentation).

Looking for **Luckysheet**? [Luckysheet](https://github.com/dream-num/Luckysheet) and [Luckyexcel](https://github.com/dream-num/Luckyexcel) are archived. Start new integrations with Univer.
